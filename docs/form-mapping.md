# 官网表单字段映射

这是官网自动填表能力的前置模块。当前版本先做“可检查、可编辑、可复制”的字段映射，不直接自动提交申请。

## 当前能力

- 从投递资料包中提取姓名、邮箱、电话、城市、学校、专业、学历、岗位方向、技能关键词、简历文件等字段。
- 每个字段维护中英文别名，例如 `Full Name / Name / 姓名`，用于后续匹配不同公司 Careers 表单字段。
- 每个字段可以重新选择资料来源，也可以手动编辑字段值。
- 支持单字段复制和一键复制全部字段，方便当前阶段人工投递官网。
- 顶部导航新增“表单映射”页面。
- 用户修改过的字段映射会保存到 SQLite，刷新页面后仍会保留；点击“重置映射”会清空自定义配置并回到资料包默认推导。

## 后端接口

- `PUT /api/form-mappings`：保存当前用户的自定义字段映射。
- `DELETE /api/form-mappings`：清空当前用户的自定义字段映射。
- `GET /api/bootstrap`：启动时返回已保存的 `formMappings`。

## 后续步骤

1. 增加公司官网表单识别：读取输入框、下拉框、附件上传字段和字段标签。
2. 将识别到的官网字段与本地字段映射做匹配。
3. 展示提交前确认页，让用户逐项确认或修改。
4. 仅在用户确认后执行填表或提交。
5. 把投递结果写入 CRM 状态与跟进记录。

## 合规边界

- 不绕过验证码、登录限制或平台风控。
- 不自动提交用户未确认的申请。
- Boss 和 LinkedIn 优先保留搜索辅助、导入和人工确认流程。
